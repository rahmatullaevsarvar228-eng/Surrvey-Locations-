# Контроль качества анкет (AnketaQC)

Десктоп-приложение для Windows: ищет статистические признаки фальсификации в
выгрузке полевого опроса (Kobo Toolbox или любая другая система) и помечает
подозрительные анкеты и интервьюеров для ручной проверки супервайзером.

Работает офлайн. Данные уходят наружу только при явном запросе к Google Sheets.
Настройки проектов и история по волнам лежат в одном SQLite-файле на этом
компьютере: `%LOCALAPPDATA%\AnketaQC\anketa_qc.db`.

## Установка

1. Откройте вкладку **Actions** репозитория → последний успешный запуск
   **Windows build — AnketaQC** → скачайте артефакт `AnketaQC-windows`.
2. Запустите `AnketaQC-Setup-<версия>.exe`. Права администратора не нужны:
   программа ставится в профиль пользователя и создаёт ярлык на рабочем столе.
3. Вместо установщика можно взять `AnketaQC-portable-<версия>.zip`, распаковать
   его и запускать `AnketaQC.exe`.

Окно приложения рисуется через Microsoft Edge WebView2. В Windows 10 и 11 он
уже встроен. На старых системах без него поставьте
[WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

## Как пользоваться

1. **Проект.** Для каждого проекта создайте свой (кнопка «+» слева). Колонки,
   пороги, правила и список значений запоминаются для проекта.
2. **Данные.** Перетащите Excel-файл или вставьте ссылку на Google Sheets.
   Ссылку достаточно вставить один раз, дальше данные обновляются кнопкой
   «Обновить и проверить». Если в файле несколько листов, выберите лист
   с анкетами (по умолчанию подставляется `data`).
3. **Колонки.** Укажите Device ID, старт, финиш, город, код интервьюера.
   Необязательные поля: ID анкеты, телефон и ФИО (нужны для поиска дубликатов),
   а также колонки-признаки завершённого интервью. Частые названия колонок
   подставляются автоматически.
4. **Пороги, открытые вопросы, правила.** Всё настраивается в окне, без правки
   кода.
5. **Проверить.** Результаты раскладываются по разделам «Обзор», «Интервьюеры»,
   «Анкеты», «Города», «Ответы», «Повтор значения». Кнопка «Отчёт Excel»
   сохраняет полный отчёт.
6. **Сохранить волну** (внизу «Обзора»). Раздел «История» покажет, кто
   несколько волн подряд остаётся в жёлтой или красной зоне.

## Что проверяется

| Проверка | По умолчанию |
|---|---|
| Нет Device ID | брак |
| Одно устройство под несколькими кодами интервьюера (и наоборот) | предупреждение |
| Длительность меньше минимума (только у завершённых интервью) / больше максимума | брак |
| Интервал между стартами анкет на одном устройстве | брак |
| «Отдых»: время между концом предыдущей анкеты и началом следующей | брак |
| «Конвейер»: N+ анкет за окно в M минут на одном устройстве | брак |
| Доля одного интервьюера в городе, минимум интервьюеров на город, доля анкет без телефона | по городу |
| Анкета начата вне рабочего времени (время берётся местное, как в выгрузке) | предупреждение |
| Дубликат респондента: тот же телефон (последние 9 цифр) | брак |
| Дубликат респондента: те же имя и фамилия в том же городе | предупреждение |
| Глубина зондажа: в блоке открытого вопроса меньше ответов, чем минимум | предупреждение |
| Среднее число ответов интервьюера ниже X% медианы волны | брак |
| Пользовательские правила «если … то …» | задаётся в правиле |
| Повтор одного значения у интервьюера (по списку значений проекта) | отдельный статус |

Ответы-заглушки («не знаю», «999», «bilmayman» и т.п.) не засчитываются как
названное значение. Их список можно редактировать.

Статус интервьюера считается по доле брака в его анкетах: 🔴 от 50%,
🟡 от 20%, 🟢 ниже. Пороги меняются на странице «Пороги проверок».

## Для разработчика

```bash
cd qc_app
pip install -r requirements.txt
python run_app.py              # нативное окно
python -m anketa_qc --browser  # тот же интерфейс в браузере (удобно для отладки)
python -m pytest -q tests
python tools/make_demo.py demo.xlsx   # демо-выгрузка с «нечестными» интервьюерами
```

Устройство:

- `anketa_qc/engine.py`: все проверки. Технический движок взят из
  `cheat_detector.py`/`main.py` без изменения логики.
- `anketa_qc/sources.py`: Excel и Google Sheets.
- `anketa_qc/history.py`: SQLite с настройками проектов и историей волн.
- `anketa_qc/export.py`: оформленные Excel-отчёты.
- `anketa_qc/server.py`: локальный API для интерфейса.
- `anketa_qc/web/`: интерфейс (HTML/CSS/JS без внешних библиотек).
- `packaging/`: сборка PyInstaller, установщик Inno Setup, иконка.

Сборка на Windows вручную:

```bat
pip install -r requirements.txt pyinstaller
pyinstaller packaging\anketa_qc.spec --noconfirm
iscc packaging\installer.iss
```

### Google Sheets

- **Открытая таблица.** В Google Sheets выберите «Настройки доступа → Все,
  у кого есть ссылка → Читатель». Приложение скачает таблицу напрямую
  у Google через официальный экспорт `.xlsx`.
- **Закрытая таблица.** Создайте в Google Cloud сервисный аккаунт с доступом
  к Google Sheets API, скачайте JSON-ключ и откройте таблице доступ на
  e-mail этого аккаунта. Путь к ключу укажите на странице «Данные». Ключ
  остаётся на этом компьютере.
